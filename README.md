# Mahir Trade V1.0.0

## Description
Mahir Trade project built with Golang, designed with Figma and documented with Postman.

## Getting Started

1. Clone the repository: `git clone https://github.com/your-username/your-project.git`
2. Install Golang: [https://golang.org/dl/](https://golang.org/dl/)
3. Build the project: `go build`
4. Run the project: `./your-project`

## Project Structure

```
mahir-trade-be/
├── cmd/
│   └── mahir-trade-be/
│       └── main.go (entry point of your application)
├── internal/  (application code)
├── .gitignore
├── go.mod
├── go.sum
├── README.md

```

- `main.go`: Entry point of your application.
- `README.md`: Documentation for your project.
- `.gitignore`: List of files and directories to be ignored by Git.
